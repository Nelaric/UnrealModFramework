UnrealModFramework is a UE 5.6 development project for a portable game-side mod runtime and an independently built mod authoring editor. The repository currently contains the project and plugin module skeletons. Package loading, content resolution, native mod APIs, and editor workflows remain to be implemented and validated.

Paths below are relative to the repository root. The UE project lives in `UnrealModFramework/`; repository configuration, documentation, and quality scripts live alongside it.

| Path | Purpose |
| --- | --- |
| `UnrealModFramework/UnrealModFrameworkDev.uproject` | Development host project |
| `UnrealModFramework/Plugins/ModRuntime/` | Game-side source plugin; `Source/Runtime/` and `Source/Editor/` group its modules by target |
| `UnrealModFramework/Plugins/ModRuntime/Tools/ModSDKTool/Resources/DevelopmentEditor/` | Source resources for the authoring plugin generated by MDT |
| `Docs/CodingStandards/` | Project coding and contribution standards |
| `.circleci/config.yml` | UE 5.6.1 Linux build configuration |
| `Scripts/` | Local quality checks |

`Binaries`, `Intermediate`, `Saved`, and `Dist` are generated output and are excluded from Git. `ModSDKTool build-editor` generates the authoring plugin in a temporary workspace, compiles it with UAT `BuildPlugin`, and publishes the verified package.

See the [coding standards](Docs/CodingStandards/README.md), [contribution guide](CONTRIBUTING.md), and [CircleCI setup](Docs/CircleCI.md) before changing code or build files.

## Quick start

1. Install the C++20 toolchain for your platform.
2. Clone the repository and enter its root directory.

   ```sh
   git clone https://github.com/Nelaric/UnrealModFramework.git
   cd UnrealModFramework
   ```

3. Run Setup for your platform.

   | Platform | C++ toolchain | Command |
   | --- | --- | --- |
   | Windows | MSVC and the Windows SDK | `.\Setup.bat` |
   | Linux | GNU `g++` | `sh Setup.sh` |
   | macOS | GNU `g++`, selected through `CXX` | `sh Setup.sh` |

Setup can use CMake 3.20 or later from `PATH`. On a fresh checkout without a suitable CMake, Setup downloads the pinned Kitware archive and verifies its SHA-256 hash. The initial download requires network access. [CMake package manifest](Setup/CMakePackages.txt)

Setup builds Release versions of the standalone tools `ModHeaderTool`, `ModBuildTool`, `ModSourceTool`, and `ModSDKTool`. Find each executable under `UnrealModFramework/Plugins/ModRuntime/Tools/build/<tool>/` and run it with `--help` to check that it starts. With Ninja or Unix Makefiles, pass `--jobs 8` to limit the build to eight parallel jobs.

### Export macro fields

Field names and allowed values are case-sensitive and defined in [ModExportMetadataSchema.h](UnrealModFramework/Plugins/ModRuntime/Source/Runtime/ExportMetadata/Public/ModExportMetadataSchema.h).

| Macro | Required fields | Optional fields |
| --- | --- | --- |
| All three | — | `ExportVersion` defaults to `"1.0.0"`, plus `DisplayName` and `Description` |
| `MOD_EXPORT_API` | `Scope`, `Thread`, `FailureRule` | `Permissions` defaults to an empty list, plus `FullView` and `CompatibleNames` |
| `MOD_EXPORT_EVENT` | `SourceScope`, `PublishRule` | `PayloadType` |
| `MOD_EXPORT_HOOK` | — | `ContextType`, `AllowedStages` (defaults to `(Post)`), and `AllowedOperations` (defaults to `()`) |

For the Unreal host build and its libclang configuration, see [ModRuntime UHT integration](UnrealModFramework/Plugins/ModRuntime/Source/ModRuntimeUht/README.md).

## SDK build tool

`ModSDKTool` (MDT) provides `plan`, `build`, and `inspect` for game-specific SDK bundles, plus `build-editor` for the standalone authoring plugin. Build it with `Tools/Build.bat --target ModSDKTool`. See the [MDT guide](UnrealModFramework/Plugins/ModRuntime/Tools/ModSDKTool/README.md) for the request and artifact formats.
